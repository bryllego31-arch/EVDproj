# Team Task Plan (real work, real commits)

The instructor checks each member's **own commits**, so each person should do their part themselves, understand it, and commit it in small steps. Suggested tasks (pick or adjust):

| Member | Files | Tasks (one commit per task) |
|---|---|---|
| Member 1 | `index.html` | Replace placeholder business text with your group's real info; add a Contact/Location section; add 2–3 more menu items to `MENU` |
| Member 2 | `style.css` | Tune colors/fonts; improve mobile layout; add hover effects; add a favicon or logo |
| Member 3 | `main.py` (cart) | Add a "Clear cart" button; show item count in the header; add a new promo code |
| Member 4 | `main.py` (forms), `README.md` | Add email validation; add an order-type note field; fill in README names and live link; upload the video |

## Commit message examples (use your own, describing what you actually did)
- `Add Contact section with shop hours`
- `Make menu grid responsive on mobile`
- `Add clear cart button and handler`
- `Validate phone number format in checkout`

## Before the video
Every member should be able to explain the whole `main.py`, not just their own part.
