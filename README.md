# Kape Cebu – Business Website (PyScript)

Final Project for **Event-Driven Programming**. An interactive coffee shop website where all logic runs in Python via [PyScript](https://pyscript.net).

## Features / Events demonstrated
| Event | Where |
|---|---|
| `input` | Live menu search, feedback character counter |
| `click` | Category filter, add to cart, +/- quantity, promo, feedback |
| `change` | Pickup/delivery selector recalculates total |
| `submit` | Checkout form with validation |

Other concepts: event delegation, dynamic DOM updates, calculations (subtotal, discount, fee, total).
